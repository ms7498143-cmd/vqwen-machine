Adding a device (future tasks)

platform/
  api/<name>.js     handler (req, res) -> runs on Vercel
  lib/measure.js    real CPU / memory / storage / network primitives
  lib/infer.js      real model inference (transformers.js, ONNX)
  device/           python device program + model registry
  models.json       registered models
  public/           home, chat, docs

Add a file under api/, push to main, and it is live.

Honest limits

ephemeral functionsStorage written inside a function does not persist between requests. Use a database or object store for durable data.
memory capHobby plan caps a function at 2048 MB; configured here at 3009 MB target with graceful fallback.
no GPUVercel provides CPU only. Large models do not fit; small quantized models do.
cold startThe model is fetched on first use, so the first request is slower. Later requests reuse the in-memory pipeline.
throughputA single device is bounded by one function core. Aggregate throughput scales by running many devices in parallel — a real sum of real measurements, not a projection.
not new siliconThese are shared cloud CPUs, not hardware you own. The platform is real infrastructure, but it is rented.
