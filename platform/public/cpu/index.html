A CPU clone that runs on Vercel

This is an independently implemented x86-64 engine. It decodes real machine-code bytes and executes them against its own registers, flags and memory. The neural network below runs on it: the forward pass is x86-64 machine code that the clone decodes and executes instruction by instruction. No math library performs the inference.

Neural network running on the clone

The network is a small character model. Its weights are integers, and its whole forward pass — every multiply and add — is x86-64 machine code. When you press Generate, the clone decodes and executes that code, one instruction at a time, and the returned instruction count is the number it actually executed.
