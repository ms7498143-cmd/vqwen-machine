Honesty — what is real, what is emulated

real
Executed work with measured output: model inference, storage I/O, TCP transfer, kernel-enforced CPU affinity and memory cap.
emulated
This device is a software reimplementation. It owns a real, isolated allocation on a host machine — it is not new physical silicon, and it does not add physical capacity. Host resources are partitioned, not created.
